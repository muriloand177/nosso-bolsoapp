👛 Nosso Bolso — Gestão Financeira Familiar
O Nosso Bolso é um projeto criado para simplificar o controle das contas de casa e a divisão de despesas entre casal ou moradores, eliminando a complicação de planilhas e focando em uma experiência leve e intuitiva direto pelo celular.

💡 A Ideia do Projeto
A proposta do aplicativo é oferecer uma visão clara da saúde financeira da casa em tempo real. O sistema permite cadastrar rendas, lançar contas a pagar e calcular automaticamente a divisão dos custos — seja de forma 50/50 ou proporcional à renda de cada um —, exibindo o saldo final e a sobra estimada para o mês.

🛠️ Tecnologias Utilizadas
Front-end: HTML5, Tailwind CSS e JavaScript.

Back-end & Nuvem: Supabase (Autenticação e Banco de Dados PostgreSQL).

Hospedagem: Netlify.
